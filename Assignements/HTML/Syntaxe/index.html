Syntaxe HTML

Le code de cette page comporte plusieurs erreurs de syntaxe HTML.

Pouvez vous en trouver 5 ?

Erreurs dans le code :

  • Erreur #1 : Les balises ouvrante et fermante "li" et "/li" doivent être enfants d'une balise "ul (unordered list)", d'une balise "ol (ordered list)", ou d'une balise "menu".
  • Erreur #2 : La balise fermante de la balise "div" qui suit la balise body n'existe pas. Il y a plutôt une seconde balise ouvrante "div" (au lieu de "/div") juste avant la balise fermante "/body".
  • Erreur #3 : Il semble que la balise text ne soit pas un élément html.
  • Erreur #4 : L'attribut "id" est une liste dans la balise "h1" alors que l'attribut "id" ne permet pas de supporter des listes comme valeurs.
